GM account for the remote consoleUsed to stop the server cleanly and run commands. Needs GM level 3. Stored only on this PC, in Dashboard\dashboard.json.
Start SPP database autosave with the serverThe SPP backup daemon that zips your database every 15 minutes.
Run server windows hiddenDatabase, login, world and autosave start with no windows. Use the Console tab for commands. Applies to the next start.
Keep bots near my levelOn every server start, random bots outside ±N levels of your last played character re-roll into that range (new level, gear and spells) as they log in. Death knights stay 55+.
Daily restartRestarts the server once a day so bots re-sync to your level. The dashboard must be running and the PC awake at that time; a missed time is skipped, not run later.
Skip the daily restart if someone is logged inOff: players get a 10-minute in-game countdown, then the restart. Characters are saved first either way.
Clear stuck sessions when the game closesIf the game client crashes or is closed from in the world, the server keeps your character's session, and the next login then crashes the client on the first chat line. When Wow.exe closes, the dashboard kicks any real character still online so you log in clean. Needs the GM account above.
